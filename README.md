# Lumina - Modern E-Commerce Store

This is a full-stack e-commerce storefront built from scratch. 

## Features
- **Frontend:** Next.js (React) and Tailwind CSS for a sleek, modern UI.
- **Database:** Supabase (PostgreSQL) to store products and user orders.
- **Authentication:** Google OAuth via Google Cloud Console.
- **Emails:** Automated order confirmations via Mailgun API.

## How to run locally
1. Clone the repository.
2. Run `npm install`.
3. Add your Supabase and Mailgun keys to a `.env.local` file.
4. Run `npm run dev`.
